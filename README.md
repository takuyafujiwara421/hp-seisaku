# まちのホームページ屋さん

関東の中小企業・個人事業主向けホームページ制作サービスのサイト（GitHub Pagesで公開）。

- `index.html` … サービス本体（強み／制作事例／料金／制作の流れ／FAQ／問い合わせ）
- `assets/style.css` … 共通スタイル。デモは `:root` の色だけ差し替えて使う
- `demo/koumuten/` … 工務店のデモ（**架空**）
- `demo/gyosei/` … 行政書士事務所のデモ（**架空**）
- `demo/cafe/` … 喫茶店のデモ（**架空**）

## 注意

- デモはすべて**架空の事業者**。各ページ上部に明記し、`noindex` を付けている
- 画像を1枚も使っていない（撮影素材が無くても納品できることを示すため）
- スマホ対応を売る以上、**横スクロールが出たら不合格**。390px幅で `scrollWidth == clientWidth` を必ず確認する
  - ★Chrome headless は `--window-size=390` を指定しても実際は **500px幅**でレンダリングして切り取るだけ。
    スマホ表示の検証は「390pxのiframeに入れて測る／撮る」こと
- 開業後に**特定商取引法に基づく表記**（事業者名・所在地・連絡先・支払方法・キャンセル規定）を追加すること
